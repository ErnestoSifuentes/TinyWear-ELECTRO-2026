# Componentes de terceros

La estructura inicial incluye referencias a herramientas externas y los textos de las licencias. Los códigos, bibliotecas del modelo y materiales adicionales se incorporan al completar el curso.

## Herramientas externas

| Herramienta | Referencia oficial |
|---|---|
| Arduino IDE | https://www.arduino.cc/en/software |
| Soporte Arduino para ESP32 | https://github.com/espressif/arduino-esp32 |
| Python | https://www.python.org/ |
| Matplotlib | https://matplotlib.org/ |
| Edge Impulse | https://docs.edgeimpulse.com/ |
| Google Colab | https://colab.research.google.com/ |
| LibreOffice | https://www.libreoffice.org/ |

Cuando se incorpore una biblioteca, un SDK, una figura o un dataset de otra fuente, se registra su nombre, origen, versión y licencia. Se conservan los archivos `LICENSE`, `NOTICE` y los avisos que acompañen al componente.

La biblioteca exportada por Edge Impulse incluye componentes del SDK; sus avisos se conservan junto con la biblioteca completa. La licencia MIT del código propio no sustituye las licencias de esos componentes.

## Textos de licencia

- MIT: texto estándar obtenido de la [lista SPDX](https://github.com/spdx/license-list-data/blob/main/text/MIT.txt), con el titular y el año del autor.
- CC BY 4.0: [texto legal oficial de Creative Commons](https://creativecommons.org/licenses/by/4.0/legalcode.txt), conservado íntegro en `LICENSES/CC-BY-4.0.txt`.
