# Sketch de inferencia TinyWear

Se descarga y conserva la [carpeta completa del sketch](TinyWear_Inferencia_WIFI/). Arduino IDE debe abrir el archivo `.ino` dentro de esa carpeta.

- [TinyWear_Inferencia_WIFI.ino](TinyWear_Inferencia_WIFI/TinyWear_Inferencia_WIFI.ino).
- [TinyWearApp.cpp](TinyWear_Inferencia_WIFI/TinyWearApp.cpp).
- [TinyWearApp.h](TinyWear_Inferencia_WIFI/TinyWearApp.h).
- [TinyWearConfig.h](TinyWear_Inferencia_WIFI/TinyWearConfig.h).

Antes de compilar se instala la [biblioteca del modelo](../Modelo/README.md). El procedimiento se consulta en la [guía PDF de P3](../../Documentos/Guias/P3_Entrenamiento_Inferencia.pdf). Se regresa a [P3](../README.md).
