# Créditos

**Autor y coordinador del material:** Dr. Ernesto Sifuentes de la Hoya.

**Adscripción:** Universidad Autónoma de Ciudad Juárez.

**Curso:** Diseño de sistemas TinyML para instrumentación electrónica inteligente.

**Caso práctico:** TinyWear, instrumentación wearable inteligente para reconocimiento de actividad humana.

**Evento:** ELECTRO 2026.

Para citar el material se utiliza el archivo [CITATION.cff](CITATION.cff). Al completar el repositorio se agrega allí su URL definitiva y se actualiza la versión cuando se publique una nueva entrega.

## Herramientas utilizadas

El taller emplea Arduino IDE, el soporte ESP32 de Espressif Systems, Python, Matplotlib, Edge Impulse y, como recurso complementario, Google Colab. Estas herramientas se identifican como componentes externos; sus autores conservan los derechos y avisos correspondientes.

Las contribuciones posteriores se reconocen en este archivo o en el historial de cambios. Véase [TERCEROS.md](TERCEROS.md).
