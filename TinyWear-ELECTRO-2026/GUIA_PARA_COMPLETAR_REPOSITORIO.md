# Mantenimiento del repositorio

El repositorio del taller está publicado en [https://github.com/ErnestoSifuentes/TinyWear-ELECTRO-2026](https://github.com/ErnestoSifuentes/TinyWear-ELECTRO-2026). El material se conserva en la carpeta `TinyWear-ELECTRO-2026`; el README de la raíz ofrece los accesos para los estudiantes.

## Incorporar o actualizar material

1. Se conserva la ubicación de cada práctica y la estructura completa de sus programas.
2. Se suben los archivos a la misma carpeta del repositorio mediante **Add file → Upload files**, o con Git.
3. Se comprueba que el nombre, las mayúsculas y la extensión coincidan con los utilizados en los enlaces.
4. Se actualiza el README de la carpeta y se verifica que sus enlaces abran los archivos.
5. Se registra el cambio en [CHANGELOG](CHANGELOG.md).

Los programas se organizan en [P1](P1_Adquisicion/README.md), [P2](P2_Dataset/README.md) y [P3](P3_Modelo_Inferencia/README.md). Las guías y las presentaciones se agregan en [Documentos](Documentos/README.md).

## Compartir con los estudiantes

Se comparte la URL principal del repositorio o un código QR con esa misma dirección. El material se descarga mediante **Code → Download ZIP** y se comienza por [00_Preparacion](00_Preparacion/README.md).

Se regresa al [inicio](README.md).
