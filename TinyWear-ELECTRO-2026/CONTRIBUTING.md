# Aportaciones al material

Las mejoras se proponen mediante Issues o Pull Requests. Se indica la práctica afectada, el problema observado y el resultado esperado.

## Cambios en programas

- Se conserva el nombre y la carpeta principal del sketch o paquete.
- Se explica el cambio y se comprueba la función afectada.
- Se documentan las dependencias y la configuración necesarias.
- Se registra la modificación en [CHANGELOG.md](CHANGELOG.md).

## Cambios en documentos

Se mantiene una redacción clara e impersonal, con pasos breves y resultados esperados. Las figuras conservan sus créditos y las versiones editables se acompañan de PDF cuando resulte útil.

Las aportaciones originales se integran bajo las licencias correspondientes al tipo de archivo, según [LICENCIAS.md](LICENCIAS.md). Los materiales externos conservan sus propios avisos.

Las dudas y los errores se registran en Issues, indicando la práctica y el programa afectados. Se incluye el mensaje completo y el procedimiento que permite reproducirlo.
